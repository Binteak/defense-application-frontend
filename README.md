# Defense Application — Frontend

Modern web frontend for a defense-oriented application focused on **operational monitoring, data visualization, geospatial information and situational awareness**.

The application provides an interactive dashboard with operational data, visual analytics and map-based information through a modern and responsive user interface.

## 🚀 Technologies

* **Vue.js** — Frontend framework
* **Vuetify** — UI components and application layout
* **Tailwind CSS** — Utility-first styling and responsive design
* **Chart.js** — Interactive charts and data visualization
* **Leaflet** — Interactive maps and geospatial visualization
* **JavaScript / HTML / CSS** — Core web technologies
* **Vite** — Development server and build tool

## ✨ Main Features

* 📊 Interactive operational dashboards
* 🗺️ Geospatial visualization with Leaflet
* 📈 Data visualization with Chart.js
* 🎨 Responsive UI built with Vuetify and Tailwind CSS
* 🖥️ Modern component-based architecture using Vue.js
* 📱 Responsive design for different screen sizes
* ⚡ Fast development and production builds with Vite

## ⚙️ Installation

Clone the repository:

```bash
git clone <repository-url>
cd frontend_vue
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will be available through the local development URL provided by Vite.

## 📦 Production Build

Create a production build with:

```bash
npm run build
```

The generated files will be placed in the `dist/` directory.

## 🛠️ Development

This project follows a component-based architecture using Vue.js. UI components and layouts are implemented primarily with Vuetify and Tailwind CSS, while Chart.js and Leaflet are used for data and geospatial visualization.
